🔄 System Phases Explained

Phase 1: Setup & Knowledge Preparation

Human defines the scorable task and the system optionally runs preparatory loops for deep research and solution recombination to gather domain knowledge and novel approaches.

Root Node Generation

Based on the chosen search type (Standard, Guided, Replication, or Recombination), the system generates an initial baseline solution to start the tree search.

Phase 2: Main Tree Search Loop

Iterative PUCT-based tree search that selects promising nodes, expands them with LLM-generated mutations, evaluates code in sandbox, and backpropagates results.

Final Output

The system continuously tracks the best-performing solution and outputs the final optimized code that achieves the highest score on the defined metric.
