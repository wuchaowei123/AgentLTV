## Core Components

### 1. Runner (`core/runner.py`)

The main evolution loop that orchestrates the entire process.

```python
class EvolutionRunner:
    def run_patch(self):
        """Main evolution loop"""
        for generation in range(max_generations):
            # 1. Sample parents from population
            parents = self.sampler.sample()
            
            # 2. Get external knowledge (if plateau detected)
            knowledge = self.knowledge_manager.get_knowledge(...)
            
            # 3. Generate mutation prompt
            prompt = self.build_mutation_prompt(parents, knowledge)
            
            # 4. Query LLM for code mutation
            new_code = self.llm_client.query(prompt)
            
            # 5. Evaluate new code
            score = self.evaluator.evaluate(new_code)
            
            # 6. Add to population if good
            if score > threshold:
                self.database.add(new_code, score)
```

## Usage

### Running Evolution

```bash
# Basic run
python -m ea.launch_hydra task=ctr_prediction

# With specific models
python -m ea.launch_hydra task=ctr_prediction llm.models=[gemini-2.5-flash]

# With knowledge search enabled
python -m ea.launch_hydra task=ctr_prediction knowledge.enable_arxiv=true
```

### Programmatic Usage

```python
from ea.core.runner import EvolutionRunner
from ea.llm import LLMClient
from ea.kosmos.knowledge import HybridKnowledgeManager

# Initialize
llm = LLMClient(model_names=['gemini-2.5-flash'])
knowledge = HybridKnowledgeManager(plateau_threshold=10)

# Run evolution
runner = EvolutionRunner(
    llm_client=llm,
    knowledge_manager=knowledge,
    max_generations=100
)
best_code = runner.run()
```

## Performance Tips

1. **Use fast models for iteration**: `gemini-2.5-flash` for quick experiments
2. **Enable knowledge search**: Helps break plateaus with new ideas
3. **Tune plateau threshold**: Lower = more exploration, higher = more exploitation
4. **Use island evolution**: Maintains diversity in population
5. **Monitor costs**: Use `pricing.py` to track LLM costs

## Conclusion

AgentLTV is a modular, extensible system for evolutionary code optimization. The key components are:

1. **Core Engine**: Evolution loop with LLM-based mutations
2. **Knowledge System**: External knowledge injection for plateau breaking
3. **LLM Integration**: Multi-provider support with fallbacks
4. **Database**: Island-based population management
5. **Evaluation**: Safe, sandboxed code execution

The system is designed to be flexible and can be adapted to various ML optimization tasks.
